TASH — Online Store

TASH is a modern and responsive e-commerce website designed for selling products directly to customers.

🚀 Features

* Modern TASH storefront
* Responsive design for mobile, tablet and desktop
* Product categories
* Product search
* Product cards
* Shopping cart
* Wishlist
* Checkout form
* Cash on Delivery option
* Local cart storage
* Mobile-friendly interface

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* GitHub Pages

📦 Current Version

This is the frontend version of TASH.

The current version uses demo products and a frontend-only checkout system.

🔜 Future Features

* User login and signup
* Supabase database
* Real product management
* Admin dashboard
* Real customer orders
* Razorpay payment integration
* Order tracking
* Product reviews
* Coupons and discounts
* Customer support
* Delivery integration

🌐 Deployment

The website can be deployed using GitHub Pages.
